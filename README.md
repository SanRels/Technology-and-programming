# Информационные технологии и программирование

Учебный веб-проект по дисциплине **«Информационные технологии и программирование»**.

Проект развивается в рамках лабораторных работ: от освоения системы контроля версий Git до создания и оформления веб-страниц с использованием HTML и CSS.

## 👨‍💻 О проекте

Репозиторий содержит результаты лабораторных работ по дисциплине.

В рамках курса изучаются:

- система контроля версий Git;
- работа с удалёнными репозиториями GitHub;
- структура HTML-документа;
- основные HTML-теги;
- CSS и способы подключения стилей;
- селекторы и специфичность;
- блочная модель;
- отступы, границы и скругления;
- позиционирование и центрирование элементов;
- тени и другие декоративные эффекты.
